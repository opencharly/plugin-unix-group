# 2026.322.2150 — test(params): gate the committed params artifact at the lockstep spec pin

## Summary

Adds the params reproducibility gate and the CI workflow that lets it run, moves the pins the gate needs, and carries **one real source fix the bump surfaced**.

- **Artifact: byte-identical.** `charly candy params plugin-unix-group` reports `already current` and the diff is empty — the generated file is not in this commit. So this is a class-A change (opencharly/opencharly#1109): the pin moved, the artifact did not.
- **Gate**: `spec/schemaparams.Generate` — the same function `charly candy params` calls — asserts the committed bytes are CURRENT and that a second run is byte-identical. Copied verbatim from the merged canary (plugin-adb#21, `8dc9907`), package name and plugin name in the message only.
- **Workflow**: this repo carried only `tag-on-merge.yml`; the org-required validator never runs a repo's `go test`. `.github/workflows/ci.yml` runs gofmt → vet → build → test **with `-count=1`**, so a cached PASS cannot satisfy a reproducibility gate.
- **Pins**: `spec v0.2026232.520 → v0.2026320.1252`, `sdk v0.2026234.347 → v0.2026320.1345` — the lockstep pair.

### The bump's one real consequence

`spec.CheckContext` gained a method, so this repo's test double no longer satisfied the interface:

```console
vet: ./plugin_test.go:50:46: cannot use cc (variable of type *fakeCC) as kit.CheckContext value in argument to verb{}.RunVerb: *fakeCC does not implement spec.CheckContext (missing method InvokeProvider)
```

`InvokeProvider(ctx context.Context, class, word, op string, paramsJSON, env []byte) ([]byte, error)` is the interface's new provider-dispatch seam. `fakeCC` gains a no-op returning `(nil, nil)` — **a test double gaining a method the interface added, not a behaviour change**, and no production code is touched.
